# features

Действия пользователя, которые приносят ему пользу: кнопка + её логика.

Импортирует: `entities`, `shared`. Слайсы этого слоя друг друга не импортируют.

Слайсы:
- `upload-file/` - загрузить файл или выбрать тестовый пример
- `map-columns/` - разметить колонки (форма с валидацией)
- `exclude-service-rows/` - отметить служебные строки (доставка, комиссии)
- `change-settings/` - валюта, страна праздников
- `search-item/` - поиск товара
- `pick-periods/` - выбор двух периодов для сравнения
- `run-forecast/` - посчитать прогноз
- `forget-data/` - удалить мои данные с сервера

Наружу - только через `index.ts` слайса.
