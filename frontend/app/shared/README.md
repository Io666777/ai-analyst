# shared

Общее, без знания о бизнесе: можно перенести в любой другой проект.

Импортирует: только внешние библиотеки. Из других слоёв - ничего.

Сегменты:
- `api/` - клиент запросов к FastAPI, обработка ошибок, общие типы ответа
- `ui/` - базовые компоненты: VButton, VSelect, VInput, VMetric, VChart...
- `lib/` - помощники: форматирование денег, дат, процентов
- `config/` - константы: адрес API, маршруты

У каждого сегмента свой `index.ts` - снаружи импортируем только из него:
`import { VButton } from '~/shared/ui'`
