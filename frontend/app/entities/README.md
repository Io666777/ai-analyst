# entities

Сущности предметной области: что это такое и как выглядит, без действий пользователя.

Импортирует: `shared`. Слайсы этого слоя друг друга не импортируют.

Слайсы:
- `session/` - номер сессии, отчёт о подготовке данных, настройки (валюта, страна, исключения)
- `column-role/` - роли колонок и их подписи
- `sales/` - ряды по периодам, итоги месяца, топ
- `item/` - товар
- `forecast/` - прогноз и отчёт о точности

Сегменты слайса (только нужные): `ui/`, `model/`, `api/`, `lib/`.
Наружу - только через `index.ts` слайса: `import { useSessionStore } from '~/entities/session'`
