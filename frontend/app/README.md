# Структура фронта: Feature-Sliced Design на Nuxt 4

Слои сверху вниз. Слой импортирует только из слоёв **ниже** себя, слайсы одного слоя друг друга не импортируют.

| Слой | Где | Что |
|---|---|---|
| app | `app.vue`, `layouts/`, `plugins/`, `assets/` | корень, макет, подключения, глобальные стили |
| pages | `pages/` | маршруты Nuxt; страницы тонкие - только собирают виджеты |
| widgets | `widgets/` | крупные блоки страниц |
| features | `features/` | действия пользователя |
| entities | `entities/` | сущности предметной области |
| shared | `shared/` | общее, без знания о бизнесе |

Особенности Nuxt:
- auto-import компонентов и наших composables выключен (`nuxt.config.ts`) - всё импортируется явно через `index.ts` слайса
- встроенные `ref`, `computed`, `useRoute` и т.п. остаются автоматическими
- разделы анализа - отдельные маршруты `pages/analysis/*`: код раздела грузится только при открытии
