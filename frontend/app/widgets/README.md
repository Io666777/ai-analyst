# widgets

Крупные самостоятельные блоки страницы: собирают features и entities в готовый кусок интерфейса.

Импортирует: `features`, `entities`, `shared`. Слайсы этого слоя друг друга не импортируют.

Слайсы:
- `analysis-nav/` - переключатель разделов
- `setup-panel/` - файл + разметка + настройки
- `month-summary/` - «как прошёл месяц» крупными цифрами
- `revenue-chart/` - динамика по месяцам
- `top-list/` - топ: график + таблица
- `item-card/` - всё о товаре
- `compare-result/` - было / стало
- `forecast-report/` - прогноз, график, причины точности

Наружу - только через `index.ts` слайса.
